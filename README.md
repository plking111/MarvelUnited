## 游戏介绍

《漫威联合》（Marvel United）是一款 1-4 人的合作桌游：玩家扮演超级英雄，通过打出行动牌获得行动符号（移动 / 攻击 / 英勇 / 万能），在地图上移动、攻击暴徒与爪牙、营救平民、清除威胁、完成三个任务，最终击败反派。反派也有自己的回合：移动、BAM！、特殊效果、放置平民/暴徒，步步紧逼。

### 目前已实现（基础版 + 扩展内容）

**反派（21 名）**
- 基础盒：红骷髅（恐惧轨道）、奥创（全地点占领 / 奥创克隆体）、模仿大师（危机护体 / 三种陷阱威胁）
- 无限战争：灭霸（KO 替换、无限宝石 / 能量卡）、暗夜比邻星、黑矮星、乌木侯
- 瓦坎达：基尔格蒙（危机占槽 / 邪恶阴谋）
- 阿斯加德：洛基（面朝下行动牌 / 幻象 / 诡计大师 / 孤独判定）
- 银河护卫队：罗南
- 蜘蛛侠扩：绿魔
- 邪恶六人组：秃鹫、神秘客、章鱼博士、猎人克莱文、沙人、电光人
- 第一季众筹：亡刃将军、泽莫男爵（危机指示物盖住行动符号 / 6 张威胁卡同回合凑英勇）、摩多克、康（时间大师 / 康不在场机制）

**英雄（57 名）**
- 基础盒、瓦坎达、阿斯加德、银河护卫队、蜘蛛侠扩
- **第一季众筹三批共 37 名**（黄蜂女起，含奇异博士、尚气、绯红女巫、月光骑士、刀锋战士、霍华德怪鸭、惊奇女士等）
- 每位英雄 12 张行动牌（含专属特殊效果卡）

**地点（32 张，随机取 6）**
- 基础盒 8 张 + 无限战争若干 + 瓦坎达 6 + 阿斯加德 6
- 每张地点卡都有独特的回合结束效果

**规则系统**
- 完整回合流程：反派回合（翻牌 → 移动 → 威胁到达 → BAM → 特殊效果 → 放置）与英雄回合（打牌 → 执行行动 → 卡牌效果 → 行动指示物 → 地点结束效果）
- 威胁卡系统（普通威胁需 3 个英勇指示物清除 / 爪牙需打生命值；含持续效果）
- 任务系统：营救平民 / 击败暴徒 / 清除威胁（各 4 格，完成 2 个解锁攻击反派）
- 伤害 / 弃牌 / KO / 复活、恐惧轨道、屠宰轨道、危机指示物、行动指示物
- 无限战争战役：无限宝石 / 能量卡 / 终局之战
- 濒危地点模式（challenge=endangered）
- 面朝下行动牌底层规则
- 卡牌悬停放大、角色移动动画
- 英雄按顺位选择、行动可跳过 / 返回、行动用完自动结束回合
- 模式选择界面（1基础/2中等/3困难/4英雄挑战/5神盾局&泽维尔/7无限战争/9濒危地点已实现，其余待扩展）
- **局域网联机**：房主权威（host 跑规则引擎、客户端只发意图）、状态快照同步、手牌隐私（他人手牌只下发背面与张数）、大厅与联机向导、角色控制权与投票
- 无限战争 4 局战役、S6 模式、叛徒模式、秘密身份模式、B 计划模式

## 开发、测试与打包

**自动化测试**（每个测试是一个独立的 headless Godot 进程，渲染类测试在 headless 下自我跳过）：

```powershell
# 全量（分段跑，每段 3 分钟总断路器，卡死会列出未跑到的测试）
powershell -File tools\run_tests.ps1 -TotalLimitSec 180
# 只跑指定测试
powershell -File tools\run_tests.ps1 -Tests zemo_test,modok_test
# 局域网双进程联机测试
powershell -File tools\run_net_test.ps1
```

`tests/` 里有 4 个登记在案的**遗留测试**默认跳过（`groot_draw_test` / `photonblast_test` / `rocket_gamora_deep_test` / `ronan_ko_fix_test`），属已知欠债。

**导出可执行版**：

1. 需要 Godot 4.7.2 的 export templates。
2. 命令行导出**必须用 console 版引擎**（`Godot_v4.7.2-stable_win64_console.exe`）——非 console 版跑 `--export-release` 会只打一行 banner 就退出、产物不更新（静默失败），导出后务必核对 pck 时间戳。
3. 把 `data/*.json` 拷到导出目录的 `data/`（数据外置，方便热改）。

**打安装包**：`tools/installer.iss`（Inno Setup 7），版本号改顶部 `MyAppVersion` 与 `OutputBaseFilename`，然后 `ISCC.exe tools\installer.iss`。

**目录约定**：`src/` 源码、`data/` JSON 数据、`tests/` 测试场景、`tools/` 开发脚本（切片 / 数据生成 / 测试运行器）、`docs/` 各批次交接文档与进度备忘（`docs/项目进度备忘.md` 记录了全部踩坑与验证分级，改规则前建议先看）、`assets/` 卡图资源。

- 数据以**卡图为准**，不臆造卡面数据；新增反派用 `tools/gen_<反派>.ps1`（幂等合并 + 自校验断言）生成数据。
- PowerShell 脚本需保留 **UTF-8 BOM**（Windows PowerShell 5.1 解析需要）。

## 技术栈

- [Godot 4.x](https://godotengine.org/)（GDScript，GL Compatibility 渲染）
