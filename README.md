## 游戏介绍

《漫威联合》（Marvel United）是一款 1-4 人的合作桌游：玩家扮演超级英雄，通过打出行动牌获得行动符号（移动 / 攻击 / 英勇 / 万能），在地图上移动、攻击暴徒与爪牙、营救平民、清除威胁、完成三个任务，最终击败反派。反派也有自己的回合：移动、BAM！、特殊效果、放置平民/暴徒，步步紧逼。

### 目前已实现（基础版内容）

**反派（3 名）**
- 红骷髅：恐惧轨道（到达 20 即失败）
- 奥创：全地点占领、奥创克隆体爪牙
- 模仿大师：危机护体、纠缠陷阱 / 爆炸陷阱 / 精锐暴徒威胁

**英雄（5 名）**
- 美国队长、钢铁侠、惊奇队长、绿巨人、黑寡妇
- 每位英雄 12 张行动牌（含专属特殊效果卡）

**地点（8 张随机取 6）**
- 中央公园、复仇者大厦、复仇者庄园、斯塔克实验室、时代广场、纽约警局总部、神盾局总部、天空母舰
- 每张地点卡都有独特的回合结束效果

**规则系统**
- 完整回合流程：反派回合（翻牌 → 移动 → 威胁到达 → BAM → 特殊效果 → 放置）与英雄回合（打牌 → 执行行动 → 卡牌效果 → 行动指示物 → 地点结束效果）
- 威胁卡系统（普通威胁需 3 个英勇指示物清除 / 爪牙需打生命值）
- 任务系统：营救平民 / 击败暴徒 / 清除威胁（各 4 格，完成 2 个解锁攻击反派）
- 伤害 / 弃牌 / KO / 复活、恐惧轨道、危机指示物、行动指示物
- 卡牌悬停放大、角色移动动画（反派多步移动逐步播放）
- 英雄按顺位选择（P1-P4，彩虹色标识）、行动可跳过 / 返回、行动用完自动结束回合
- 27 个模式选择界面（基础模式与神盾局单人模式已实现，其余为占位待扩展）

## 技术栈

- [Godot 4.x](https://godotengine.org/)（GDScript，GL Compatibility 渲染）
- 数据驱动：英雄 / 反派 / 地点 / 任务 / 模式均由 JSON 配置，扩展内容只需添加数据与素材
- 模块化：UiKit（共享 UI 工厂）、PopupLayer（弹窗层）、LocationView（地点卡）、MissionView（任务卡）
