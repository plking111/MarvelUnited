## 5. 新增机制说明

### 5.1 威胁卡"生命值 + 英勇槽"双路径
泽莫的 5 张威胁卡卡面**同时**印了生命值图标和"同一回合内用 N 个英勇行动击败"的说明，
而引擎原先的二选一模型（`hp > 0` = 只能打、`hp == 0 + clear` = 只能填符号）表达不了。
现在：只要威胁卡带 `clear`，就同时开放两条路——
- 攻击（`attack` 符号）扣 `hp`，`hp <= 0` → 移除；
- 英勇行动填 `clear` 槽，填满 → 移除（且受裁定③的同回合限制）。

### 5.2 `same_turn_clear`（裁定③）
`_start_hero_turn()` 一开始就把所有带 `same_turn_clear` 的威胁卡的 `clear_progress` 清空。
即"一回合"= **一个英雄的回合**；同一英雄回合内多次放英勇可以累积到填满。

### 5.3 覆盖符号的存储与传播
- 存储：`Game.state["story"][i]["covered"] = [符号下标…]`（英雄卡条目上的新键，永久保留）。
- 继承：`_last_hero_card_symbols()` 只返回未被覆盖的符号 → 下一位英雄拿不到被盖的符号。
- 引用：`_count_recent_story_symbols()` 同样跳过被覆盖的符号。
- 联机：`covered` 就在 `state["story"]` 里，`Net.visible_state_for()` 只裁剪面朝下卡片的 `idx`，
  所以快照天然带 `covered`（`zemo_test` "⑪" 已验证）。

## 6. 口径与解释

**✅ 已裁定三项（用户 2026-09，均已落地，别再当"待确认"）**：

1. **"同一回合"= 一个英雄的回合内**（保持现状，**不用改代码**）：
   即"新英雄回合开始就清空没凑满的英勇进度"（`_reset_same_turn_threats()` 在 `_start_hero_turn()` 最前面），
   不是"一轮（所有英雄各行动一次）"。
2. **月石没有英勇槽**（只能靠伤害打掉）：数据里 `clear` / `same_turn_clear` 两个字段不写
   （生成器 `T()` 按 `heroic_n > 0` 决定，并加断言强制），引擎靠 `_threat_placeable_sym` 的
   "hp>0 且无 clear → 不可放"分支生效；`zemo_test` 断言这两个键不存在。
3. **电光人面板 BAM 以现实现为准、只改文案不改代码**：这是「卡图优先」的**例外**（用户裁定）——
   见 §2.3 第 7 条；`_electro_bam` 一行未动，`electro.bam` 文案已对齐代码。

**其余仍属我自行判断、请复核的部分**：

4. **公民五没有平民时**：场上不存在"拥有最多平民的地点" → 泽莫**不移动**，但仍结算"丢弃所在地点所有平民和暴徒"。
5. **平手的两种情形口径不同**：BAM/溢出的"最近英雄"若同一地点有多名英雄 → **玩家选择**（裁定④）；
   公民五找"平民最多的地点"若有并列 → 取**顺时针先遇到**的那个（卡面没有玩家选择的说法）。
6. **"最近的英雄"不含已 KO 的英雄**（KO 英雄下回合才复活，无法承接指示物）。
7. **面朝下的英雄卡**（秘密身份挑战的暴露出牌）不参与覆盖：危机指示物留在英雄身上，等下次打出正面卡时再盖。
8. **0 符号的行动卡**（数据里有 13 张）同样无法覆盖，危机全部留在身上。
9. 伤害沿用引擎既有口径（弃手牌 / 无手牌才 KO）；"丢弃平民/暴徒"沿用暗夜比邻星口径（**不推恐惧轨道**）。
10. 同地点多名英雄要选一人受伤时（泽莫 BAM、歌利亚 BAM）用 `_ask_pick_hero()` 弹窗；只有 1 名英雄时不弹窗。
