## 0. 一句话概括

摩多克的核心机制是**把故事情节里的英雄卡翻成正面朝下**（面朝下 = 空白）：
面板 BAM / 溢出 / 行动卡 10-11 / 威胁卡 能量投射·斑点 都在翻英雄卡，翻的目标永远是
**故事情节中最靠前的正面朝上英雄卡**（`story` 下标 0 一侧 = 故事情节开始）；
**所有英雄卡都面朝下 → 英雄失败**（恶毒的阴谋）。
行动卡 1「制备」有**特殊设置**：它必定是摩多克打出的第一张行动卡。
